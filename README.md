### `> whoami`

```bash

```

### `> cat /etc/features.conf`

```yaml
⚡ Multi-threaded:
  - Scans multiple ports simultaneously for blazing fast results.
🎯 Custom Port Ranges:
  - Specify exactly which ports you want to scan.
🛠️ Banner Grabbing:
  - Identifies the service running on the open port.
```

### `> ./installation.sh`

```bash
# 1. Clone the repository
git clone https://github.com/LiveMedia48/Port-Scanner.git

# 2. Navigate to the directory
cd Port-Scanner

# 3. Install dependencies (if any)
pip install -r requirements.txt
```

### `> ./run.sh`

```bash
python scanner.py -t 192.168.1.1 -p 1-1000
```
*Replace `192.168.1.1` with your target IP and `1-1000` with your desired port range.*
